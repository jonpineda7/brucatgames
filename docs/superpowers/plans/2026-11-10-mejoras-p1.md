# Mejoras P1 de BruCat Games — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolver el desbordamiento horizontal de Infantil, reducir JS inicial y recuperar la navegación cuando falla la descarga de un módulo de juego.

**Architecture:** Ajustar solo la capa decorativa que rebasa el contenedor; usar `React.lazy` para las seis vistas de juego; envolver las importaciones diferidas con un límite React que permita recargar la ruta actual o regresar al catálogo. Conservar el hash router y los componentes de juego.

**Tech Stack:** React 19, Vite 8, CSS existente, Node test runner y Chrome para pruebas de interfaz.

**Spec:** `docs/auditoria-brucat-games.md`, hallazgos A2–A4.
